# Project Status (harness)

Flywheel extension app: one high-level status view across projects for data managers, task managers and compute managers (Data / Tasks / Compute lenses).

- **Contains no data.** All demo data is synthetic and generated in the browser. Live mode reads Flywheel through the Extension SDK (ReadOnly scope, GET only) with the signed-in user's permissions.
- Research use only; not validated.
- Demo outside Flywheel: open `index.html` (or this site with `?demo=1`).
- Source of record: `project-status-<version>-src.zip` in each release commit.
